# Kivio Desktop v2.9.3

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包** — `Kivio.Desktop_2.9.3_x64-setup.exe`（NSIS / installer）
- **Windows 便携版** — `Kivio.Desktop_2.9.3_x64-portable.zip`（解压即用，不写开始菜单 / unzip and run `Kivio Desktop.exe`）
  - 需要已安装 Edge WebView2（Windows 10/11 通常已有）。Requires the Edge WebView2 runtime.
  - 设置和对话与安装版共用用户目录。Settings and chats are shared with the installed app.
  - 应用内更新仍下载安装包，不会原地覆盖 zip。In-app update still downloads the NSIS installer.
- **macOS** — `Kivio.Desktop_2.9.3_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`
  - First launch: right-click → Open, or run `xattr -cr "/Applications/Kivio Desktop.app"`

## 新版本亮点

- **便携版** —— Windows 增加解压即用的 zip，不写开始菜单、不跑安装向导。
- **DeepSeek 搜索** —— 官方搜索进入供应商列表，内置托管搜索可用；修好 Responses 成功体解析，并补上 Logo。
- **MCP** —— 已加载服务按来源分组。OAuth token 会刷新，远程 HTTP 会话保持活着。
- **外部 CLI** —— 跟上 Claude Code 2.1.238、Codex 0.148（动态 / 图片 / sleep 工具）、dsh rc.8 斜杠图片与 V4 Flash Vision。Grok 从共享 leader 拆开。Codex 沙箱逃逸改为询问而不是静默拒绝。Claude / Codex 模型按 cc-switch 方式持久化。自定义 dsh 预设出现在输入框。
- **聊天** —— 附件发送后保持输入框那种小卡片。最后一轮可换模型再答。Kivio Agent / Chat 可切断上下文。侧栏可重新生成标题。Ox Alpha 进入模型目录。
- **设置** —— 编程计划预设提前，从弹窗挑选。
- **修复与精简** —— 侧栏归档不再带动邻行；Windows 保持 ClearType；对话库表头贴齐卡片；排队直到引导落地才消失。去掉轨迹 Dock、捆绑 Pyodide、账户菜单里的检查更新，以及 Kivio Chat 那篇内置长提示。

## What's New

- **Portable Windows build** — unzip-and-run zip, no Start Menu and no setup wizard.
- **DeepSeek search** — official search joins the provider list and hosted builtin search works; Responses success bodies parse correctly, with the logo.
- **MCP** — loaded servers are listed grouped by source. OAuth tokens refresh and remote HTTP sessions stay alive.
- **External CLIs** — catch up Claude Code 2.1.238, Codex 0.148 (dynamic / image / sleep tools), and dsh rc.8 slash images plus V4 Flash Vision. Grok is isolated from the shared leader. Codex sandbox escapes ask instead of silently rejecting. Claude / Codex chat models persist the cc-switch way. Custom dsh agent presets appear in the composer.
- **Chat** — sent attachments stay as the compact composer cards. Reply to the last turn with another model. Kivio Agent / Chat can cut context. Sidebar can regenerate titles. Ox Alpha joins the model catalog.
- **Settings** — coding-plan presets come first and are picked from a modal.
- **Fixes and cleanup** — sidebar archive no longer twitches neighboring rows; Windows keeps ClearType; the conversation library header meets the card; the mid-run queue stays visible until steer / follow-up lands. Removes the trajectory dock, bundled Pyodide, check-for-updates in the account menu, and Kivio Chat's built-in prompt essay.
