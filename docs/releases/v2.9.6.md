# Kivio Desktop v2.9.6

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_2.9.6_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_2.9.6_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包。In-app updates download the NSIS installer.
- **macOS** — `Kivio.Desktop_2.9.6_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

- **OAuth 账号接入 / OAuth accounts** — 支持 Codex、Kimi 和 Antigravity OAuth，新增账号身份与额度展示。Connect Codex, Kimi and Antigravity through OAuth, with account identity and usage information.
- **Antigravity CLI** — 接入官方 CLI，支持流式会话、斜杠命令及命令结果面板；改善慢速模型探测和错误提示。Use the official CLI with streamed conversations, slash commands and command-result panels, plus improved model discovery and error reporting.
- **模型档位一致性 / Model effort consistency** — Antigravity CLI 与 OAuth 的档位模型保留原始名称，隐藏重复的强度设置，阻止旧值覆盖模型档位。Effort-specific Antigravity models keep their original names; duplicate effort controls and conflicting overrides are removed.
- **OpenCode Free 与模型目录 / OpenCode Free and model catalog** — 新增无需 API Key 的 OpenCode Free 供应商，补齐模型元数据与图标，并更新模型目录。Add anonymous OpenCode Free access, complete its model metadata and icons, and refresh the model catalog.
- **插件与工作流 / Plugins and workflows** — 新增 Kivio v1 插件包和工作流 hooks。Add Kivio v1 plugin packages and workflow hooks.
- **聊天操作 / Chat controls** — 输入框支持方向键回看输入历史和提示词优化；整理附件、图片预览与信息来源入口，多模型并排更充分利用宽度。Browse input history with arrow keys, optimize prompts, and use more compact attachment and image previews with improved multi-model layouts.
- **窗口界面 / Window layout** — 收紧外沿与面板间距，优化 Windows 窗口按钮及最大化/还原图标同步，统一独立窗口顶栏背景并补齐标题拖动。Reduce panel spacing, refine Windows controls and maximize/restore state, and align popout titlebar styling and dragging.
- **流式与稳定性 / Streaming and reliability** — 修复生成结束和过程展开时的闪动、跳动；改善参考图传递、图片方向与体积处理、前台进程等待及取消清理，并更新多种外部 CLI 适配。Reduce streaming and disclosure jumps, improve reference-image handling and image orientation/size, and strengthen process waiting, cancellation and external CLI compatibility.
