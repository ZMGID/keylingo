# Kivio Desktop v2.8.6

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows** — `Kivio.Desktop_2.8.6_x64-setup.exe`（NSIS 安装包 / installer）
- **macOS** — `Kivio.Desktop_2.8.6_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`
  - First launch: right-click → Open, or run `xattr -cr "/Applications/Kivio Desktop.app"`

## 新版本亮点

- **实时协议版本化** — 聊天的实时通信收进单条 `chat-protocol` 通道：运行事件带版本与序号，会话事件带 revision，断线可按快照重放，类型与 JSON Schema 由 Rust 侧生成后提交。配套修掉会话持久化的并发竞争、侧栏刷新的全量扫盘与独占锁、一个订阅者抛错毒死整条流、空 delta 的段占位被吞。
- **从本地 CLI 导入对话** — 绑定了文件夹的项目新增「从 CLI 导入对话」，列出工作目录等于项目根的原生会话并导入成 Kivio 对话，续聊仍由原 CLI 承担。支持 claude / codex / grok / kimi / opencode。历史是一次性快照、不与 CLI 同步（附过期提示）。
- **每个供应商单独的请求配置** — 供应商详情新增「请求配置 ›」：自定义请求头（可从 JSON / cURL 粘贴导入，中转站要的 X-Title 之类终于有地方填）、跟随系统代理开关、prompt caching、按 Claude Code / Codex / Grok 伪装客户端身份。prompt 缓存不再只有 Anthropic，OpenAI 协议也覆盖到了。
- **侧栏可手排，对话可钉位** — 集与项目改为拖拽排序（此前项目按「上次改名时间」倒序，作为「最近使用」是假信号）；展开后的对话也能拖，钉在放下的那一行，其余按时间填空位。「最近」平铺列表保持纯时间线。
- **Grok (xAI) 独立为一种接口协议** — xAI 的 Responses 端点严格拒收一批 OpenAI 专有字段，思考档位也是自己一套。新增协议选项后不再每个会话白扔一次 400；系统提示词搬进 `input[0]` 而不是删掉，`store:false` 显式下发（xAI 默认存 30 天，而 Kivio 从不用 `previous_response_id`）。
- **修一批流式、删除与渲染缺陷** — 断流回落非流式的超时从 60s 提到 600s（high reasoning + 十万 token 根本不可能在 60 秒内答完）；同一张图 read 两次不再在历史里留两份 base64（实测占请求体 74%）；新增 Timeout 失败分类并带上供应商原始报错；流式表格不再被贪婪正则拆成段落；删除对话不再因 dev server 钉住工作区而整体中止、刷新后又冒回来。
- **重会话切换从约 1 秒降到接近瞬时** — 渲染策略的判据从「消息条数」换成成本估算：实测一个 14 条消息的对话因 231 个代码块渲出 5433 个 DOM 节点，条数少不代表便宜。重会话走向上渐进加载而非虚拟化（本应用行高差三个数量级，按消息粒度虚拟化结构性地做不到不跳）；代码块外壳瘦身、高亮结果加缓存。
- **底部跟随不再抽搐或卡死** — 滚动跟随改为按事件来源判定：拖原生滚动条、页内查找、focus 滚动、iframe 滚动链都产生不了 wheel，此前这些情况下会和外部反复互写 scrollTop，表现是贴底时整个列表抽搐、滚动条拖不动。
- **聊天界面接上语言开关** — 聊天窗从来没做过 i18n，设置切到 EN 而聊天仍是中文。常驻外壳（侧栏、标题栏、输入栏、顶栏各选择器、右键菜单、轮次导航）共 145 个新键，中英双侧。
- **退出不再漏孤儿子进程** — 退出清理里的 `tokio::time::timeout` 当参数传给 `block_on`，在进入运行时之前求值就 panic，导致它之后的整段清理从未执行：外部 CLI 会话、后台命令进程组、OCR sidecar、插件预览每次关窗都在漏。
- **外部 CLI 模型选单** — Claude Code 只保留四档家族 catalog 并应用 settings/env 映射，Codex 以精选四模型为主；修 Claude 多轮模型映射与 Codex effort 边界。
- **HTML 预览不再边生成边重载** — 内容还在长时只渲染源码，静默 600ms 才挂 iframe；指针在预览里滚也能带动聊天列表。
- **其它** — Off 思考档显式下发 `none`/`disabled` 而不是默认 high；设置页齐边铺满；Mica 在拖窗与缩放时不再闪；最大化图标在非整数缩放下不再缺边。
- **移除项（不兼容）** — AI 客户端设置里的「流式输出」与「思考模式」两个开关删除，行为固定为开启；手动关过的用户下次启动会被改回开启。

## What's New

- **Versioned realtime protocol** — chat realtime traffic moved onto a single `chat-protocol` channel: run events carry a version and sequence number, conversation events carry a revision, a dropped connection replays from a snapshot, and the TypeScript types and JSON Schemas are generated from Rust and committed. Along with it: conversation persistence is now concurrency-safe, sidebar refresh no longer scans the whole disk or takes an exclusive lock, one throwing subscriber no longer poisons the stream, and empty-delta segment placeholders are no longer swallowed.
- **Import conversations from a local CLI** — projects bound to a folder gain "import conversation from CLI": it lists native sessions whose working directory is the project root and imports them as Kivio conversations, with the original CLI still driving the continuation. Supports claude / codex / grok / kimi / opencode. History is a one-time snapshot, not synced with the CLI (with a staleness note).
- **Per-provider request configuration** — provider detail gains a "Request config ›" page: custom headers (importable by pasting JSON or cURL, so relay-required headers like X-Title finally have a home), a follow-system-proxy toggle, prompt caching, and client-identity spoofing as Claude Code / Codex / Grok. Prompt caching is no longer Anthropic-only; the OpenAI protocols are covered too.
- **Hand-ordered sidebar and pinned conversations** — sets and projects are now drag-reordered (projects used to sort by "last renamed", a fake recency signal); expanded conversations can be dragged too and pin to the row you drop them on while the rest fill the remaining slots by time. The flat "Recent" list stays a pure timeline.
- **Grok (xAI) is its own wire protocol** — xAI's Responses endpoint strictly rejects a set of OpenAI-only fields and has its own effort ladder. With a dedicated protocol option, no conversation burns a 400 to learn that anymore; the system prompt moves into `input[0]` instead of being dropped, and `store:false` is sent explicitly (xAI defaults to keeping responses for 30 days and Kivio never uses `previous_response_id`).
- **A batch of streaming, deletion, and rendering fixes** — the non-streaming fallback timeout went from 60s to 600s (high reasoning over 100k tokens cannot possibly finish in 60 seconds); reading the same image twice no longer leaves two base64 copies in history (measured at 74% of the request body); a new Timeout failure class carries the provider's raw error; streaming tables are no longer collapsed into paragraphs by a greedy regex; and deleting a conversation no longer aborts wholesale because a dev server pinned the workspace, only for the conversation to reappear on refresh.
- **Switching into a heavy conversation dropped from ~1s to near-instant** — the render strategy is chosen by estimated cost rather than message count: one 14-message conversation rendered 5433 DOM nodes from 231 code blocks, so few messages does not mean cheap. Heavy conversations use progressive upward loading instead of virtualization (row heights here span three orders of magnitude, so per-message virtualization structurally cannot avoid jumping). Code-block chrome is slimmer and highlight results are cached.
- **Pin-to-bottom no longer twitches or locks up** — scroll follow is now decided by event source. Dragging the native scrollbar, in-page find, focus scrolling, and iframe scroll chaining produce no wheel event, and the old code fought whoever else was writing `scrollTop` — the list twitched at the bottom and the scrollbar would not move.
- **The chat UI honors the language switch** — the chat window never had i18n, so switching settings to EN left chat in Chinese. The persistent shell (sidebar, titlebar, composer, top-bar pickers, context menus, turn navigation) gained 145 keys in both languages.
- **No more orphaned child processes on exit** — the exit cleanup passed `tokio::time::timeout` as an argument to `block_on`, which evaluates before entering the runtime and panics, so everything after that line never ran: external CLI sessions, background command process groups, the OCR sidecar, and plugin previews leaked on every window close.
- **External CLI model menus** — Claude Code keeps four family entries and applies settings/env mapping, Codex leads with four curated models; fixes Claude's multi-turn model mapping and Codex effort bounds.
- **HTML preview stops reloading while it generates** — while content is still growing it renders as source and only mounts the iframe after 600ms of silence; scrolling with the pointer inside the preview now moves the chat list too.
- **Also** — the Off effort level sends `none`/`disabled` explicitly instead of defaulting to high; the settings page fills edge to edge; Mica no longer flashes while dragging or resizing; the maximize glyph no longer loses an edge at fractional display scaling.
- **Removed (breaking)** — the "streaming" and "thinking mode" toggles are gone from AI client settings and both are permanently on; anyone who had turned one off will find it back on at next launch.
