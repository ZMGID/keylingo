# Kivio Desktop v2.10.0

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包** — `Kivio.Desktop_2.10.0_x64-setup.exe`（NSIS / installer）
- **Windows 便携版** — `Kivio.Desktop_2.10.0_x64-portable.zip`（解压即用，不写开始菜单 / unzip and run `Kivio Desktop.exe`）
  - 需要已安装 Edge WebView2（Windows 10/11 通常已有）。Requires the Edge WebView2 runtime.
  - 设置和对话与安装版共用用户目录。Settings and chats are shared with the installed app.
  - 应用内更新仍下载安装包，不会原地覆盖 zip。In-app update still downloads the NSIS installer.
- **macOS** — `Kivio.Desktop_2.10.0_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`
  - First launch: right-click → Open, or run `xattr -cr "/Applications/Kivio Desktop.app"`

## 新版本亮点

- **自动化** —— 全新的线性画布：触发器（手动 / 定时 / 热键）接 Agent、命令、通知、文件、HTTP 等节点，画好即跑；Agent 也能用原生工具查看、编辑、运行自动化。空闲零轮询：调度器只在下一次触发点醒来。
- **会话弹出窗口** —— 任意对话可以弹成独立窗口继续聊，流式互不干扰，主窗不再为弹出的会话花一分力气。
- **活体 Kivio** —— 流式指示器换成一只有呼吸、有眼神、会被戳的蓝色小家伙；空闲时自动降帧，屏外完全休眠。
- **会话目录** —— 一条对话可以授予多个额外目录，跨项目干活不再来回切。
- **供应商** —— 新的供应商设置与模型连通性测试；API Key 池可指定当前使用的 key；下线模型自动从选择器隐藏；新增混元 / Seed / GLM 目录名。
- **联网搜索** —— `web_fetch` 可以配置自己独立的供应商。
- **性能** —— 运行中回答的协议快照加了体积上限；自动化并发有帽、退出时统一收尾不留孤儿进程；未列出模型按 Pi 风格发 16k max_tokens。
- **修复** —— 中转站漏发终止事件时流式回答不再丢失；对话标题不再显示占位符；模型测试与选择器弹窗不再跳动。

## What's New

- **Automations** — a new linear canvas: triggers (manual / schedule / hotkey) flow into Agent, command, notify, file, and HTTP nodes; the Agent can also list, edit, and run automations through native tools. Zero idle polling — the scheduler wakes only at the next due fire.
- **Popout conversations** — any conversation can continue in its own window; streams stay isolated and the main window spends nothing on popped-out chats.
- **A living Kivio** — the stream mark is now a breathing, glancing, pokeable blue blob; it drops to a low frame rate when idle and sleeps entirely off-screen.
- **Conversation directories** — one conversation can grant additional directories, so cross-project work stops bouncing between chats.
- **Providers** — reworked provider setup with model connectivity testing; pick the active key from the API-key pool; retired models hide from pickers; Hunyuan, Seed, and GLM catalog names added.
- **Web search** — `web_fetch` can use its own provider.
- **Performance** — live-run protocol snapshots are size-capped; automations get a concurrency cap and clean app-exit teardown with no orphan processes; unlisted models send Pi-style 16k max_tokens.
- **Fixes** — streamed replies survive relays that omit the terminal event; conversation titles no longer show placeholders; model test and picker dialogs stop jumping.
