# Kivio Desktop v2.9.7

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows 安装包 / Installer** — `Kivio.Desktop_2.9.7_x64-setup.exe`（NSIS）
- **Windows 便携版 / Portable** — `Kivio.Desktop_2.9.7_x64-portable.zip`，解压后运行 `Kivio Desktop.exe` / unzip and run.
  - 需要 Edge WebView2，设置和对话与安装版共用。Requires Edge WebView2; settings and conversations are shared with the installed app.
  - 应用内更新仍下载安装包。In-app updates download the NSIS installer.
- **macOS** — `Kivio.Desktop_2.9.7_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`。
  - First launch: right-click → Open, or run the command above.

## 新版本亮点 / What's New

以下按功能整理 **v2.9.6 → v2.9.7** 的版本差异。This changelog covers the **v2.9.6 → v2.9.7** release range, grouped by feature.

### Kivio 自配置 / Kivio self-configuration

- **应用内自配置 / In-app self-configuration** — 新增 Kivio 自配置工具与内置 Skills，可帮助检查和配置运行时、Skills、MCP、Hooks 与插件。Add native tools and bundled Skills that help inspect and configure Kivio runtimes, Skills, MCP, hooks and plugins.
- **插件中心分类 / Plugin Center organization** — 将插件、第三方应用和连接器拆分到独立标签页，降低配置时的查找成本。Separate plugins, third-party apps and connectors into dedicated tabs for easier discovery and setup.

### 工作流自动化 / Workflow automation

- **数据映射 / Data mapping** — 工作流节点支持数据映射与插值，便于把上游输出精确传给后续节点。Map and interpolate upstream outputs into downstream workflow nodes.
- **单节点测试 / Single-node testing** — 可直接试运行单个节点，并查看运行状态和结果，加快工作流调试。Run an individual node and inspect its state and output for faster workflow debugging.
- **执行稳定性 / Execution reliability** — 改善调度、快捷键、Agent 节点、工具执行和运行状态处理，同时强化连线验证和节点间距。Improve scheduling, hotkeys, agent/tool execution and run-state handling, with stronger graph validation and node spacing.
- **编辑器交互 / Editor polish** — 对齐工作流控件，改善表单验证、节点选中和错误反馈。Align workflow controls and stabilize validation, selection and error feedback.

### 聊天与通知 / Chat and notifications

- **回复预览通知 / Reply-preview notifications** — 聊天完成通知可选择显示回复预览，并在设置中独立开关。Optionally include a reply preview in completion notifications, controlled from settings.
- **Windows 通知身份 / Windows notification identity** — 注册正确的 Windows 应用身份，改善通知的显示与唤起行为。Register the correct Windows app identity for more reliable display and activation of completion notifications.
- **专家选择器 / Expert picker** — 将专家选择器移到输入框工具栏，让常用切换更直接。Move the expert picker to the composer toolbar for quicker access.
- **阅读位置稳定 / Stable reading position** — 修复窗口宽度变化或回复节点恢复时的消息、岚岚错位和阅读位置跳动。Keep messages, Lanlan and the reader's scroll position stable across width changes and restored response nodes.

### 外部 CLI 与界面 / External CLI and interface

- **安全的 CLI 探测 / Safe CLI probing** — 读取 Antigravity 版本、授权和模型时禁用自动更新，避免只读探测启动脱离的更新进程；正常 CLI 运行与更新行为保持不变。Disable Antigravity auto-update during read-only version, auth and model probes without changing normal CLI runs or updates.
- **统一滚动条 / Unified scrollbars** — 设置页和引导页使用统一的自定义滚动条样式。Use consistent custom scrollbar styling across Settings and onboarding.
