# Kivio Desktop v2.8.5

桌面 AI 助手 · macOS (Apple Silicon) + Windows。Desktop AI assistant for macOS (Apple Silicon) and Windows.

## 下载 / Downloads

- **Windows** — `Kivio.Desktop_2.8.5_x64-setup.exe`（NSIS 安装包 / installer）
- **macOS** — `Kivio.Desktop_2.8.5_aarch64.dmg`（Apple Silicon，未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/Kivio Desktop.app"`
  - First launch: right-click → Open, or run `xattr -cr "/Applications/Kivio Desktop.app"`

## 新版本亮点

- **输入区与快捷键** — 输入框上的选择器改为紧凑的按钮锚定弹层（助手 / 多模型 / 来源统一），上下文指示器与代码块外框重做；快捷键页新增「关闭聊天窗」，补上恢复默认与占用检测。
- **一 agent 一对话** — 内置 Agent 的会话一旦有消息就锁定 agent 切换（此前只有本地 CLI 这么锁，中途换等于换个大脑接着同一段上下文）。
- **思考等级不再被静默降档** — 选 xhigh 却发出 high 的根因是按 api_format 卡的第二层白名单；「认哪几档」其实是逐模型的，现在四个适配器原样下发所选档位，能选哪几档由模型库门控，并可在模型详情里逐模型覆盖。
- **消息列表部分虚拟化** — 只虚拟化更早的历史，最近一段始终实挂载；钉底不再抢用户滚动，读历史时脚下不再跳。
- **macOS 图标适配系统外观** — 感谢 @HappyDIY（[#22](https://github.com/ZMGID/kivio/pull/22)）。
- **窗口材质与帧率** — 修好台前调度切窗掉帧（macOS 材质改为常驻，焦点交给 AppKit）；Win10 没有 Mica 时不再误判材质生效、透出桌面。
- **运行时选择** — 去掉「内置 / 本地 CLI」分段器，Kivio Agent 作为第一张卡片直接排进代理列表。
- **界面细节** — macOS 顶栏分隔线按真实交通灯中心定位；上下文圆环换成 SVG 描边；内嵌设置页与首次引导变成浮起卡片；扩展页互切与弹层展开的第一帧不再闪。
- **引导与文档** — 首次引导功能卡按现在的产品面貌重写，官网补上「右侧 Dock」与「生命周期 Hooks」两页。

## What's New

- **Composer and hotkeys** — The pickers above the composer are compact, button-anchored popovers (assistant / multi-model / sources share one spec), with a reworked context indicator and code-block chrome. The hotkeys page gains "close chat window", restore-defaults, and conflict detection.
- **One agent per conversation** — A built-in-agent conversation locks its agent once it has messages, like local CLIs already did; switching mid-conversation used to swap brains under one context.
- **No more silent reasoning-effort downgrade** — Picking xhigh but sending high came from a second whitelist keyed on api_format, but which levels a model accepts is per-model. All four adapters now send exactly what you picked, the model database is the only gate, and the model-detail drawer can override it per model.
- **Partially virtualized message list** — Only older history is virtualized; the recent window stays really mounted. Pin-to-bottom no longer fights your scroll, so the ground stops shifting while you read history.
- **macOS icon follows the system appearance** — Thanks to @HappyDIY ([#22](https://github.com/ZMGID/kivio/pull/22)).
- **Window materials and frame rate** — Stage Manager no longer drops frames (the macOS material is permanent and focus is left to AppKit), and Windows 10 without Mica no longer reports success and makes the shell see-through.
- **Runtime picker** — The built-in/local-CLI segmented control is gone; Kivio Agent is simply the first card in the agent list.
- **UI details** — The macOS titlebar divider is placed from the real traffic-light center, the context ring moved to an SVG stroke, embedded settings and first-run onboarding became floating cards, and switching extension pages or opening a popover no longer flashes.
- **Onboarding and docs** — The first-run feature cards match what the app is today, and the website gained pages for the right dock and lifecycle hooks.
